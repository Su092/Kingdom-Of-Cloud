# _Inbox — 未处理资产暂存区

**本目录入库**（换机 `git pull` 就能拿到原料）。放进来的东西是**原料**，不是交付件。

## 为什么单独放这里

工程里的 `Assets/` 只应该有「能直接进引擎」的东西。AI 原图、参考图、预览渲染混在里面会有三个问题：

1. Unity 会给每张图生成 `.meta` 和无用导入，拖慢首次打开
2. 分不清「这张处理过没有」，流水线容易读错输入
3. 仓库里塞几十 MB 可再生的大图

## 命名约定

| 子目录 | 内容 |
|--------|------|
| `ui-ai-raw/` | APIMart 原始下载，未抠图未规范化 |
| `ui-ai-src/` | 前期处理产物（已抠图 / 尺寸规范） |
| `art-refs/` | 3D 建模参考图（仅对照用） |
| `art-preview/` | 模型预览渲染 |

按需新建；不需要的子目录不建。

## 纪律

- **只有最终进引擎的产物才落到 `Assets/_Game/`**；中间态一律留在本目录。
- 本目录已入库：删掉某项就等于从所有机器删除，**不要**随手 `git clean`。
- 需要长期留存的参考图放本目录；写进枢纽 `docs/` 的只是**结论**（表格/文字），不要提交大图。
- `Assets/_Game/Res/` 只放预制体、材质、场景等运行时资产，不放原料。
