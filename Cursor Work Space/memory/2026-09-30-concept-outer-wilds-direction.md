## 世界观骨架

- **舞台**：蒸汽行星；无陆地；以**压力区**区分“深度/高度”，温度随压力递增。
- **分层**：底层为**临界态/超临界水**（无表面张力、强渗透、无明显气液过渡）；中高层为云；中间有**过渡带**。
- **调性**：蒸汽朋克科技水平。
- **奇观**：
  - **神的调色盘**：因地磁异常形成的天然奇观。
  - **环境异常**：部分云被地磁干扰凝固成固定形状。
- **资源与设施**：微量元素提取/精炼（铁、铜等）— 特殊科技设施。
- **人为凝固**：可逆；靠**锁合粒子发生器**，消耗提取所得**粒子罐**。

## 交通 / 作业工具（设定层）

- **气囊飞行器**：热气球式（生物材料 + 人为科技），用压力差深潜/上浮；适用中层及过渡带浅层。
- **深潜器**：电磁炮式；发射舱体到目标深度，任务后控密度返回；关联职业/职业病。
- **抗温压服**：深潜器出仓作业。
- **共生驯养式**：特殊生物 + 人为科技；抗高压高温；成本高。

## 玩法方案对照（文档内评估）

| 方向 | 文档判断 |
|------|----------|
| 《漂泊牧歌》式模拟经营 | 浅层云海为主；深潜/超临界体验难表现；偏小众 |
| 《潜水员戴夫》式 2D 探索 | 深潜核心理念强，但锁合粒子与云海奇观难拉开与“海”的差距；玩法 > 世界观 |
| 3D 箱庭/开放世界 RPG | 成本高；锁合粒子解密 + 深潜搜打撤有空间，后期难；世界观与玩法较平衡 |
| **类《星际拓荒》有限箱庭** | **当前倾向**：世界观占比 > 玩法；重体验、轻/无战斗 |

## 选定方向要点（类星际拓荒）

- **有限箱庭**：可反复走通、靠理解推进，而非无限开放堆量。
- **叙事前提**：宇宙经历繁荣与衰败后，谋克星球再次发展出星际航行能力，探寻星图中原有星球。
- **科技碰撞**：外来（玩家）× 本地（云端王国）。
- **动机**：外来者连接/解开云海秘密。
- **探索驱动**：**知识锁**（类银河恶魔城）— “门无法从这一侧打开”；获得特定知识或能力后才解锁新通路。
- **体验取向**：重体验，轻战斗或无战斗；世界观权重大于玩法系统堆叠。
- **待斟酌**：肉鸽？元素矩阵交互；玩家注意力的可联想性、初始知识储备、降低理解门槛、直观表达。
