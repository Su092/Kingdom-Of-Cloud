# 概念图风格 → 渲染管线建议

更新：2026-09-30  
依据：`Cursor Work Space/Doce/《云端王国》概念文档.pdf` 内嵌概念图（已抽至 `Doce/_pdf_extract/`，过程产物）  
工程现状：Unity **2022.3.62f3c1**，**Built-in RP**（`m_CustomRenderPipeline: 0`），未装 URP/HDRP  
玩法方向：类《星际拓荒》有限箱庭（重体验、可反复走通）

## 风格诊断（从概念图抽出）

- **调性**：风格化半写实 / 电影概念风（偏吉卜力·新海诚式空气感），不是赛璐璐描边，也不是写实照片级。
- **主色**：高键蓝白云海 + 前景锈红/黄铜机械对比；深层转为低键青绿/深蓝 + 生物/能源自发光。
- **视觉支柱**（决定管线取舍）：
  1. **分层体积介质**（外层云 / 过渡带超临界雾水 / 深层浑浊）与穿过屏障时的光线柱
  2. **大气透视**（远距降对比、染蓝）
  3. **HDR + Bloom**（云峰高光、青蓝推进器/锁合粒子能量）
  4. **风格化 PBR**（风化漆面金属、黄铜、玻璃舱罩；白城石材偏漫反射）
  5. **双光照域**（云上海白天 high-key ↔ 深层 low-key 局部光）
  6. **锁合粒子**：气态云 ↔ 半透锐边“凝固云”状态切换 + 光束/粒子交互

## 管线选型结论

| 候选 | 结论 |
|------|------|
| 继续 Built-in | 不推荐：自定义 Pass / 体积雾 / Renderer Feature 生态弱，后期难扩 |
| **URP（2022.3 对应 14.x）** | **推荐**：可控自定义、性能适合有限箱庭、风格化友好 |
| HDRP | 不推荐作默认：成本与写实偏向过重；行星尺度+体积云全开易失控 |

原则：**用 URP 搭“可玩的风格化电影感”，不要用全行星实时光追体积去抠概念图每一笔。**

## 建议搭建分层（由底到顶）

1. **底座**：切 URP → Forward（或 Forward+）→ Linear 色彩空间 → HDR Camera  
2. **光照基础**：主方向光（日）+ Sky/Ambient（冷蓝填阴影）+ Reflection Probe / 轻量 Probe 体积；动态区优先实时，定居点可混合烘焙  
3. **大气与景深感**：Height Fog / 自定义密度雾（按“压力深度”采样）+ 远景降对比；天空用程序化或简化大气散射，忌一开始上完整行星大气仿真  
4. **体积云（核心瓶颈）**：混合方案——远景低成本（天空盒/球面壳/Raymarch 低步数或 impostor），近景交互云用局部体积/半透网格/SDF；全屏高步数体积云只作镜头与关键区域  
5. **深度介质切换**：URP Renderer Feature / Volume 按压力区换雾色、散射、曝光与 LUT（云上 ↔ 过渡带 ↔ 深层）  
6. **材质层**：URP Lit/自定义；金属风化 mask；玻璃 Clear Coat/折射简化；凝固云用半透+SSS/厚度近似，不做真冰物理  
7. **自发光与 VFX**：青蓝 Emissive + Bloom；锁合粒子用 VFX Graph/粒子；光束用 mesh/ribbon  
8. **后处理 Volume**：Tonemap、Bloom、Color Grading（云上暖高光/冷阴影；深层压暗抬青）、可选轻微 Lens Distortion；慎用过重 DoF  
9. **箱庭尺度**：浮点原点/分区流送；远景城市用 LOD/Impostor，别指望 Nanite 级网格密度
